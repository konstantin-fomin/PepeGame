# PepeIdle — Context Prime

Загружает полный контекст проекта PepeIdle в начале сессии.
Используй эту команду вместо ручного чтения файлов при старте.

## Инструкции

Выполни следующие шаги **строго по порядку**:

### 1. Прочитай обязательные файлы контекста

```text
Read: K:\OBSIDIAN\Projects\PepeIdle\CONTEXT.md
Read: K:\OBSIDIAN\Projects\PepeIdle\MEMORY.md
Read: K:\Downloads\PepeIdle\PepeIdle\CLAUDE.md
```

### 2. Прочитай свежий daily

Найди самый свежий файл в `K:\OBSIDIAN\Projects\PepeIdle\Daily\` формата `YYYY-MM-DD.md` и прочитай его.
Если папка пуста — пропусти этот шаг.

### 3. Сверься с текущим состоянием проекта

Проверь живое состояние репозитория:
- какие скрипты реально существуют в `Assets/Scripts/`
- какие сцены в `Assets/Scenes/`
- нет ли расхождения между Obsidian-контекстом и фактическим кодом

```text
Glob: Assets/Scripts/**/*.cs
Glob: Assets/Scenes/*.unity
Glob: Assets/Data/**/*.asset
```

### 4. Явно отметь расхождения docs vs code

Если CONTEXT.md и код говорят разное:
- не скрывай это
- напиши блок `Расхождения`
- укажи чему доверяешь как более актуальному источнику

### 5. Выведи сводку сессии

---

## Контекст PepeIdle — [дата сегодня]

**Текущая задача:**
> [1-3 строки из CONTEXT.md]

**Стадия:**
> [что реально собрано сейчас]

**Последнее что сделано:**
> [2-4 пункта из daily + кода]

**Расхождения:**
> [если есть; если нет — "Явных расхождений не найдено."]

**Следующий шаг:**
> [конкретный следующий шаг]

**Активные ограничения:**
> - Валюта double, не float
> - Параметры апгрейдов только в ScriptableObject
> - Сохранения только через SaveSystem
> - [другие живые ограничения из MEMORY.md]

---

### 6. Задай вопрос и жди ответ

После сводки напиши:

**«Подтверди задачу или скажи что изменилось — и я начну работу.»**

Не приступай к коду до явного ответа пользователя.
